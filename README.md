# PapuWriter / Photo Uploader for Papu.io

Narzędzie automatyzujące wgrywanie i dopasowywanie zdjęć potraw do menu w systemie Papu.io na podstawie nazw dań.

## Wymagania

- Python 3.10+
- Google Chrome

## Instalacja zależności

```bash
pip install -r requirements.txt
```

## Uruchomienie

```bash
python photo_uploader.py
```

lub za pomocą gotowego pliku wykonywalnego:
```bash
PhotoUploader.exe
```

## Kompilacja do pliku wykonywalnego (.exe)

```bash
pyinstaller PhotoUploader.spec
```
